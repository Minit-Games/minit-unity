# CLAUDE.md — minit-unity

Unity project hosting the Minit Games Unity SDK UPM package (`games.minit.unity`, GitHub repo `Minit-Games/minit-unity`), letting Unity creators export an existing WebGL game to a Minit-compliant ZIP via a C# bridge to the host-injected `window.minit` runtime. Full maintainer reference — the `window.minit` contract, shared engine-facade pattern, distribution/release philosophy, and per-engine gotchas — lives in the consolidated SDK-maintenance doc: https://github.com/Minit-Games/minit-root/blob/develop/docs/sdk-maintenance.md
